# Programación 1 — UTN San Nicolás

## Descripción

Este repositorio tiene como objetivo reunir y organizar el material trabajado durante el cursado de la materia **Programación 1** de la **Universidad Tecnológica Nacional (UTN) — Facultad Regional San Nicolás**.

El repositorio se utilizará para acumular de manera ordenada los contenidos, ejercicios, trabajos prácticos y demás actividades realizadas a lo largo de la cursada.

## Objetivos

- Mantener organizado el material desarrollado durante la materia.
- Registrar los ejercicios y trabajos realizados durante el cursado.
- Facilitar la consulta y revisión de los contenidos trabajados.
- Mantener un registro del progreso realizado durante la cursada.

## Contenido

El repositorio podrá incluir:

- Ejercicios prácticos.
- Trabajos prácticos.
- Actividades y entregas.
- Código fuente desarrollado durante la cursada.
- Material complementario.
- Otros recursos relacionados con la materia.

## Organización

El contenido se incorporará progresivamente y se organizará según las unidades, temas o actividades correspondientes, procurando mantener una estructura clara y ordenada.

**Materia:** Programación 1
